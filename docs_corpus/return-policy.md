# Return policy

## Standard returns

Items from a **CONFIRMED** order can be returned within **30 days** of confirmation for a full
refund to the original payment method, provided the item is unused and in its original packaging.
Return shipping is free for defective or incorrectly-shipped items; for change-of-mind returns, a
return shipping label fee is deducted from the refund.

## Damaged or defective items

If an item arrives damaged or defective, you have **14 days** from confirmation to report it.
Refunds for damaged items are processed as soon as the report is reviewed — you do not need to
wait for the item to be returned first for clearly defective items (e.g. visibly broken on
arrival). We do offer full refunds on damaged items; this is separate from the standard
change-of-mind return window above and isn't subject to the return-shipping-fee deduction.

## What can't be returned

Orders that are still **PENDING** or that were **CANCELLED** were never fulfilled, so there is
nothing to return — a cancelled order is not charged. Digital or downloadable products, if any,
are not eligible for return once accessed.

## How to start a return

Returns are handled by support, not through this assistant — reference your order ID when you
reach out.
